Built for B.Tech Information Technology students. Four tracks cover what most campus recruiters test: coding, core subjects, development and system design, and aptitude with HR rounds. Pick a track, follow the links, and keep going every day.

DSA and Coding

Most online assessments start here. Learn arrays, strings, linked lists, stacks, queues, trees, graphs, and dynamic programming in that order. Solve a few problems every day instead of many on one day, and always write down the pattern you used.

LeetCode problem set NeetCode roadmap GeeksforGeeks DSA tutorial

Core CS Subjects

Interviewers ask about operating systems, DBMS, computer networks and OOP to check your basics. Know the why behind each concept: why deadlocks happen, what indexes do, what happens when you type a URL.

OSTEP (free OS book) SQL on W3Schools Harvard CS50

Development and System Design

Projects get you shortlisted and decide how the interview goes. Build something real, put it on GitHub, and be ready to explain every design choice. For system design, start with the basics: APIs, databases, caching, and load balancing.

Java roadmap Official Java tutorials System Design Primer

Aptitude and HR

Service companies and many product companies screen with aptitude tests first. Practice quantitative, logical and verbal questions under a timer. For HR rounds, prepare a clear answer to "tell me about yourself" and one story each about teamwork, failure and leadership.
